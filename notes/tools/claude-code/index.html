    Claude Code 使用手册¶

    前言：打开claude code： - 以管理员身份打开clash - 同时开启system proxy和TUN mode

    作为开发者，你不仅是在使用一个工具，而是在构建一套 AI 驱动的工程流。本手册旨在通过建立正确的"认知模型"，帮助你快速驾驭 Claude Code，实现从"手动编码"到"意图驱动"的跨越。

    1. 快速入门：环境搭建与身份认证¶

    在启动 Claude Code 之前，请确保本地已安装 Node.js。

    • 第一步：全局安装工具 — 使用 npm 将 Claude Code 集成到系统路径中
    • 第二步：身份认证与授权 — 启动 OAuth 流程，在浏览器中完成开发者身份验证
    npm install -g @anthropic-ai/claude-code
claude

    2. 三种核心模式¶

    理解模式的区别，是保持工程架构完整性的关键。

    模式 核心用途 触发方式
    默认模式 (Default) 基础交互、单文件修改与即时问答 直接输入 claude 启动
    自动模式 (Auto) 追求执行速度，允许 AI 自动连续执行操作 适用于确定性高、重复性强的任务
    规划模式 (Plan) 深度架构分析，处理跨文件重构或复杂功能 claude --plan 或会话中切换

    规划模式的核心价值在于其"先思考，后执行"的逻辑——它会强制 AI 在修改代码前先输出技术方案蓝图，有效避免在大规模工程中产生逻辑碎片。

    3. 核心术语¶

    MCP (Model Context Protocol)¶

    MCP 是连接 AI 与外部世界的标准协议。它不仅是安装，更是"能力的连接"，允许 AI 直接调用外部数据源（如数据库或设计稿）。

    Agent Skill¶

    Skill 是为 Claude 注入的"领域知识包"。它定义了 AI 在特定场景下可以调用的工具集，是提升 AI 任务成功率的专家经验沉淀。

    SubAgent¶

    SubAgent 是复杂任务下的"协作逻辑"。当主智能体判定任务规模超过单一上下文的处理能力时，会自动分发子任务给 SubAgent，实现并行开发与隔离。

    Hook¶

    Hook 是实现 AI 自动化工作流的切入点。通过定义钩子，你可以在特定生命周期（如提交代码前）强制执行 AI 检查。

    4. 进阶控制技巧¶

    版本回滚 (Rewind)¶

    适用场景：AI 在多文件重构中产生"状态污染"或引入循环依赖，无法通过 Git 快速定位错误。

    作用：将代码状态和 AI 的记忆同步回退到健康的时间点。

    会话恢复 (Resume)¶

    适用场景：深度讨论复杂逻辑时因网络异常或终端重启，导致对话上下文丢失。

    作用：无缝找回历史会话，确保逻辑链条的连续性。

    项目记忆 (CLAUDE.md)¶

    适用场景：AI 反复违反代码风格（缩进、命名规范）或业务领域的特定禁忌。

    作用：作为"工程大脑"，存储持久化的项目级指令，Claude 每次启动都会优先读取。

    跳过权限确认 (Skip Permissions)¶

    适用场景：在受信任的沙盒环境中执行大量文件读写，厌倦频繁的手动 Y/N 确认。

    claude --dangerously-skip-permissions

    安全提示

    此模式权力极大，请务必在 Git 状态干净的环境下使用，以便随时回滚。

    5. 资源管理与清理¶

    高效的上下文管理能显著降低 Token 消耗并提升 AI 的响应质量：

    指令 作用
    /tasks 查看后台异步执行的任务，防止任务僵死
    /compact AI 总结当前会话重点并清理冗余历史，释放上下文窗口
    /clear 切换不同开发任务前清除缓存，防止旧逻辑干扰新思路

    6. 核心命令速查¶

    # 初始化并进入 Claude 开发环境
claude

# 针对复杂功能开启"先规划后代码"模式
claude --plan

# 灾难恢复：撤销最近一次不理想的代码更改
claude rewind

# 断点续传：重新找回之前的开发上下文
claude resume

# 极速模式：跳过所有交互确认（仅限受信任环境）
claude --dangerously-skip-permissions
