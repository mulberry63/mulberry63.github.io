    git 命令速查¶

    常用 git 命令汇总，快速查阅。

    初始配置¶

    git config --global user.name ""
git config --global user.email ""
git config --global init.defaultBranch master  # 默认分支名改为 master

git init  # 初始化仓库

    提示

    Linux 中以 . 开头的文件和文件夹为隐藏目录，使用 ls -a 才能查看。

    提交代码¶

    暂存 (add)¶

    git add src/status_interfaces/package.xml  # 暂存单个文件
git add src                                 # 暂存某个目录
git add .                                   # 暂存当前目录所有文件
git reset                                   # 将暂存区所有文件踢出

    工程中 build/、install/、log/ 都是编译产生的目录，不建议提交，只提交 src 即可。

    提交 (commit)¶

    git commit -m "完成状态发布与显示功能"  # 提交暂存区代码并添加备注
git log                                  # 查看提交历史日志

    忽略文件 (.gitignore)¶

    创建 .gitignore 文件，git add 时会自动忽略其中列出的文件或目录：

    build/
install/
log/

    远程仓库¶

    git remote add origin <url>   # 关联远程仓库
git push -u origin master     # 首次推送并设置上游
git push                      # 后续推送
git pull                      # 拉取远程更新
git clone <url>               # 克隆远程仓库

    分支管理¶

    git branch                    # 查看本地分支
git branch <branch-name>      # 创建新分支
git checkout <branch-name>    # 切换分支
git checkout -b <branch-name> # 创建并切换
git merge <branch-name>       # 合并分支到当前分支
git branch -d <branch-name>   # 删除分支

    撤销与回退¶

    git status                    # 查看工作区状态
git diff                      # 查看未暂存的改动
git restore <file>            # 撤销工作区改动（未暂存）
git restore --staged <file>   # 撤销暂存（保留工作区改动）
git revert <commit>           # 创建一个撤销提交（安全）
git reset --hard <commit>     # 强制回退到某次提交（危险）

    注意

    git reset --hard 会丢失未提交的所有改动，操作前请确认工作区已保存。
