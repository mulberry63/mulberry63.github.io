    EGO-Planner Swarm 踩坑记录

    环境：WSL2 + Ubuntu 22.04 + ROS2 Humble

    1. RViz2 启动闪退（Segfault）

    问题： 运行 rviz2 后出现 D3D12: Removing Device 和 Segmentation fault，窗口闪退。

    解决：

    export LIBGL_ALWAYS_SOFTWARE=1
echo "export LIBGL_ALWAYS_SOFTWARE=1" >> ~/.bashrc

    原理： WSLg 通过 d3d12 后端把 3D 渲染交给 Windows 侧 GPU，这条路径不稳定。该变量强制改用 CPU 软件渲染，绕开 GPU，兼容性更好。

    2. 为什么要换 CycloneDDS？

    问题： 使用 ROS2 默认的 FastDDS 运行 EGO-Planner 时非常卡顿。

    解决：

    echo "export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp" >> ~/.bashrc
source ~/.bashrc

    原理： DDS 是 ROS2 节点间通信的中间件。FastDDS 和 CycloneDDS 功能一样但实现不同，EGO-Planner 作者发现 FastDDS 与其发布订阅模式不兼容。ROS2 允许通过一个环境变量无缝切换。

    3. .bashrc 的作用

    问题： 每次开新终端都要重新 export 环境变量。

    解决： 把 export 语句写进 ~/.bashrc 末尾即可永久生效。

    原理： ~/.bashrc 是每次打开终端时自动执行的脚本，相当于终端的开机自启动清单。

    4. 是否需要独立环境？

    问题： 担心 EGO-Planner 的依赖污染现有 ROS2 环境。

    解决： 不需要，直接建新 workspace 即可。不要把 source install/setup.bash 写进 .bashrc，用时手动 source 更灵活。

    mkdir -p ~/ego_ws

    原理： ROS2 workspace 天然隔离——编译产物都在 install/ 目录下，不 source 就不加载，不影响其他项目。只有依赖不同 ROS2 版本时才需要 Docker。

    附：当前 .bashrc 末尾配置

    source /opt/ros/humble/setup.bash
export LIBGL_ALWAYS_SOFTWARE=1
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
