    ROS2 知识手册¶

    快速参考：工作空间管理、功能包创建、节点编写。

    目录¶

    • 创建工作空间
    • 创建功能包

    • C++ 节点
    • Python 节点
    • 服务与参数

    创建工作空间¶

    mkdir -p ~/ros2_ws/src
cd ~/ros2_ws
colcon build
source install/setup.bash

    创建功能包¶

    C++ 功能包¶

    cd ~/ros2_ws/src
ros2 pkg create my_cpp_pkg \
  --build-type ament_cmake \
  --dependencies rclcpp std_msgs \
  --license Apache-2.0

    Python 功能包¶

    cd ~/ros2_ws/src
ros2 pkg create my_py_pkg \
  --build-type ament_python \
  --dependencies rclpy std_msgs \
  --license Apache-2.0

    自定义接口功能包¶

    cd ~/ros2_ws/src
ros2 pkg create status_interfaces \
  --build-type ament_cmake \
  --dependencies rosidl_default_generators builtin_interfaces \
  --license Apache-2.0

    --dependencies 参数指定功能包依赖项。

    构建功能包¶

    # 构建所有功能包
cd ~/ros2_ws
colcon build

# 构建指定功能包
colcon build --packages-select my_cpp_pkg

# 刷新环境变量
source install/setup.bash

    C++ 节点¶

    创建节点文件¶

    在 my_cpp_pkg/src/ 下新建 my_node.cpp：

    #include "rclcpp/rclcpp.hpp"

class MyNode : public rclcpp::Node
{
public:
  MyNode() : Node("my_node")
  {
    RCLCPP_INFO(this->get_logger(), "节点已启动");
  }
};

int main(int argc, char **argv)
{
  rclcpp::init(argc, argv);
  auto node = std::make_shared<MyNode>();
  rclcpp::spin(node);
  rclcpp::shutdown();
  return 0;
}

    修改 CMakeLists.txt¶

    在 find_package() 之后添加：

    add_executable(my_node src/my_node.cpp)
ament_target_dependencies(my_node rclcpp)

install(TARGETS
  my_node
  DESTINATION lib/${PROJECT_NAME}
)

    运行节点¶

    ros2 run my_cpp_pkg my_node

    Python 节点¶

    创建节点文件¶

    在 my_py_pkg/my_py_pkg/ 下新建 my_node.py：

    import rclpy
from rclpy.node import Node

class MyNode(Node):
    def __init__(self):
        super().__init__('my_node')
        self.get_logger().info('节点已启动')

def main(args=None):
    rclpy.init(args=args)
    node = MyNode()
    rclpy.spin(node)
    node.destroy_node()
    rclpy.shutdown()

if __name__ == '__main__':
    main()

    修改 setup.py¶

    在 entry_points 里添加：

    entry_points={
    'console_scripts': [
        'my_node = my_py_pkg.my_node:main',
    ],
},

    运行节点¶

    ros2 run my_py_pkg my_node

    服务与参数¶

    服务 (service)¶

    命令 说明
    ros2 service list -t 查看服务列表和接口类型
    ros2 interface show <接口> 查看服务接口的详细定义
    ros2 service call <服务> <接口> <参数> 通过命令行调用服务

    参数 (param)¶

    命令 说明
    ros2 param list 查看参数列表
    ros2 param describe <节点> <参数> 查看指定节点的参数描述
    ros2 param get <节点> <参数> 获取节点的参数值
    ros2 param set <节点> <参数> <值> 通过命令行修改参数值
    ros2 param dump <节点> > output.yaml 将参数导出到 YAML 文件
